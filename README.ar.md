**HistoryVerse** هي منصة ذكاء اصطناعي إنتاجية متعددة الوسائط والوكلاء، مصممة خصيصاً للتراث والتاريخ المصري والسكندري وجولات المتاحف التفاعلية بالواقع المعزز.

---

## 🏛️ الوكلاء المتخصصون في المنصة

1. **المرشد التاريخي العام (Mora - Historical Guide)**:
   - **الوسائط المدعومة**: محادثة نصية معمقة، تحليل الصور التاريخية والنقوش، وتوليد صور ولوحات أثرية دقيقة.
   - **التخصص**: تاريخ مصر القديمة، الإسكندرية الهلنستية والبطلمية، الحضارة الإسلامية والمملوكية، وعجائب العالم القديم.

2. **مرشد الواقع المعزز الصوتي المباشر (AR Museum Tour Guide)**:
   - **الوسائط المدعومة**: **صوت مباشر ثنائي الاتجاه حصرياً عبر WebSockets (Live Conversational Streaming Voice)**.
   - **التخصص**: الارتباط الفوري بالتمثال أو الأثر الذي يقف أمامه الزائر (`artifact_label`)، والإرشاد الصوتي باللغتين **العربية والإنجليزية** مع دعم المقاطعة الحية (Barge-in).

---

## 🛡️ الميزات الموروثة تلقائياً لكل وكيل في المنصة

يرث كل وكيل يتم إنشاؤه في منصة `HistoryVerse` الميزات المؤسسية التالية:
- **معالجة اللغة العربية وربط الحروف**: معالجة مشكلات اللام ألف (`لا`) وتحويل الأرقام المشرقية (`٠-٩`) وتصحيح الأقواس المعكوسة.
- **تطبيع العامية المصرية**: تحويل الأسئلة الدارجة (*مين بنى*، *إيه حكاية*، *فين مكان*) إلى مصطلحات بحث أثرية وتاريخية رصينة.
- **بوابة الرفض وحدود النطاق**: رفض الأسئلة غير التاريخية (كالبرمجة أو الطبخ أو الكورة) لمنع الهلوسة.
- **حجب البيانات الشخصية المصرية (PII)**: حجب أرقام الهويات الوطنية والهواتف قبل إرسالها للنماذج.
- **التحقق من المراجع والتوثيق الأثري**: منع اختلاق التواريخ أو نسب الآثار لغير بانيها.

## 🚀 التشغيل السريع في 3 أوامر

```bash
# 1. تثبيت البيئة
pip install -e .

# 2. تشغيل خط أنابيب بيانات التراث DVC
python3 scripts/dvc_pipeline.py all

# 3. تشغيل خط التدريب المستمر والاختبارات
python3 orchestration/dags/historyverse_pipeline.py
```
